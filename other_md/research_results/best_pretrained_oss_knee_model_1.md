Pretrained 2D Image Backbones for RSNA Knee Abnormality Detection: A Comprehensive Ensemble Decorrelation StrategyThe pursuit of top-tier performance in the RSNA Knee Abnormality Detection challenge—a multi-label, macro-averaged AUROC optimization problem over highly imbalanced findings—demands a sophisticated approach to model ensembling. The observation that structural and architectural variations yield diminishing returns when pretraining distributions overlap is well-documented in medical computer vision. As the competition leaderboard tightens, the highest marginal gains in a classification ensemble are consistently realized by combining models with fundamentally orthogonal pretraining objectives and disparate source datasets. Integrating models optimized via contrastive image-text mapping, self-supervised topological matching, or latent representation distillation provides an error diversity that simple architectural variations (e.g., swapping a ResNet for a ConvNeXt trained on the same ImageNet corpus) cannot achieve.The following analysis systematically identifies, evaluates, and ranks candidate 2D backbones that adhere strictly to the offline, commercial-use constraints of prize-eligible Kaggle submissions. Every model evaluated herein provides a novel pretraining paradigm distinct from standard supervised ImageNet pipelines, Masked Autoencoders (MAE), or standard DINOv2 setups, specifically targeting the detection of the twelve required MSK findings, ranging from macroscopic joint effusion to microscopic ligamentous disruptions.Licensing, Compliance, and Offline Deployment FrameworkIn competitive machine learning environments with commercial prize tracks, the bifurcation between code licenses and weight licenses is a frequent source of pipeline disqualification. LVM-Med (Large-scale Vision Model for Medical Imaging)LVM-Med represents an exceptional apex candidate for musculoskeletal and MRI tasks due to its pan-radiological pretraining dataset and structurally focused self-supervised learning strategy. For the detection of meniscal tears and anterior cruciate ligament (ACL) sprains—pathologies characterized by subtle topological disruptions in low-contrast tissue—LVM-Med provides a highly specialized feature space.The pretraining data encompasses 1.3 million medical images aggregated across 55 diverse datasets, crucially including 3D MRI modalities such as the BraTS dataset and multi-site prostate MRI databases. The fundamental innovation of LVM-Med lies in its pretraining objective: Second-order Graph Matching. Standard global contrastive learning methodologies force whole-image embeddings together, which is effective for global classifications but often suppresses fine-grained local geometry. In contrast, graph matching enforces structural and topological feature preservation across augmented views. By mathematically aligning the second-order relationships (the distances and angles between local feature nodes) across different augmentations, the model develops an acute sensitivity to anatomical continuity. This objective is theoretically optimal for detecting a fractured bone cortex or a torn medial meniscus, where the diagnostic signal is defined by a break in expected geometric continuity.The weights and the associated research codebase are distributed under the CC-BY 4.0 license, expressly permitting commercial use and redistribution. The parameters are hosted natively via Zenodo and GitHub releases linked in the primary repository (duyhominhnguyen/LVM-Med). The architecture is available in a ResNet-50 variant (25.5 million parameters) and a ViT-B variant (86.0 million parameters). For 2D slice pipelines operating at a 512x512 resolution, the ViT-B variant utilizes standard 16x16 patches. This yields an exact $32 \times 32$ patch grid, cleanly avoiding the fractional interpolation artifacts associated with patch-14 models.To deploy LVM-Med in an offline Kaggle environment, the state dictionary must be downloaded as a .pth file and attached to a standard timm backbone. RAD-DINO (Base)RAD-DINO applies the powerful DINOv2 self-distillation objective to radiological data, producing dense local features that form highly distinct clusters without relying on linguistic annotations. The value of RAD-DINO lies in its ability to detect anomalies without having been explicitly taught to classify them, relying entirely on the statistical divergence of the local patch features from normative anatomical structures.The model was pretrained via self-distillation over massive Chest X-ray datasets, including MIMIC-CXR, CheXpert, and NIH data. The objective maximizes the cosine similarity between global image views passed to a momentum-updated teacher network and local, highly augmented crops passed to a student network. This forces the student network to deduce the global anatomical context from isolated local textures. For knee MRIs, this translates to an exceptional ability to differentiate between the healthy fibrillar texture of a normal ligament and the disorganized signal of an interstitial tear.The base RAD-DINO model (microsoft/rad-dino) is distributed under the MIT license, verifying its commercial safety. It utilizes a ViT-B/14 architecture comprising 86 million parameters. However, the patch size of 14 introduces a rigid constraint for a 512x512 pipeline. Because $512 / 14 = 36.57$, passing a 512-pixel image into a ViT-B/14 will trigger a tensor shape mismatch during the unpatchify operation in PyTorch. Conversely, an input of 336x336 functions perfectly ($336 / 14 = 24$ patches). If a 512-pixel resolution is strictly required, the data preprocessing pipeline must dynamically zero-pad the image to 518x518 ($518 / 14 = 37$ patches) or center-crop it to 504x504 ($504 / 14 = 36$ patches) prior to the forward pass.Pythonfrom transformers import AutoModel

BEiT (Base, Patch-16, ImageNet-22k)If a natural-image foundation model is to be utilized within the ensemble, its objective must deviate fundamentally from continuous Masked Autoencoders (MAE) and standard cross-entropy. Despite the perfect domain overlap, the structural mismatch eliminates their utility as a simple plug-and-play backbone.Architectural Integration and Inference OptimizationTo maximize the macro-averaged AUROC for the 12 RSNA findings, the integration of these backbones into the existing pipeline requires precise architectural handling, particularly concerning resolution scaling and feature pooling.Resolution Mathematics and Patch ScalingVision Transformers operating on specific patch sizes are intolerant of fractional grids. If the pipeline extracts 512x512 pixel slices from the DICOM files, it aligns perfectly with Patch-16 models (LVM-Med, BiomedCLIP, Data2Vec, BEiT), generating exactly 1,024 tokens ($512 / 16 = 32$; $32 \times 32 = 1024$).However, integrating Patch-14 models (RAD-DINO, BioCLIP 2) requires runtime tensor manipulation. Because $512 / 14 = 36.57$, an un-padded forward pass will crash. The preprocessing module must apply symmetric zero-padding to reach the nearest divisible integer: 518 pixels. A standard torch.nn.functional.pad(x, (3, 3, 3, 3)) operation secures a $37 \times 37$ grid (1,369 tokens) without distorting the physical aspect ratio of the anatomical structures. Alternatively, if memory constraints dictate downscaling, a resolution of 336x336 is universally compatible, yielding $21 \times 21$ tokens for Patch-16 models and $24 \times 24$ tokens for Patch-14 models.Offline Deployment StrategiesFor the air-gapped Kaggle inference environment, relying on .from_pretrained("hf-id") will fail as the environment attempts to ping the Hugging Face API. The optimal workflow requires creating an offline Kaggle dataset containing the raw model weights.For models integrated natively into timm or transformers, the weights and the configuration JSON files must be downloaded locally and uploaded to Kaggle as a single dataset directory. Models trained via global contrastive learning (MedImageInsight, BiomedCLIP) output highly semantic [CLS] tokens, which respond well to simple Max Pooling across the slice dimension, as the pathology (e.g., a focal bone contusion) may only be visible on a single slice. Conversely, models trained via self-distillation or topological matching (RAD-DINO, LVM-Med) produce rich, dense token grids. For these backbones, applying an Attention Pooling layer over the flattened slice features allows the network to weight the slices dynamically, emphasizing the coronal planes for collateral ligament evaluation and the sagittal planes for cruciate ligament assessment. By maintaining strict orthogonal pretraining across the ensemble, the fused logits will exhibit the necessary decorrelation to push the leaderboard score beyond the 0.941 threshold.
